# English

## Mapping of Interface Text Strings (Ammo HUD)

These strings are used by the graphics engine to load visual assets or ammunition counter labels onto the HUD.

| Virtual Address (EE RAM) | String Value | Estimated Purpose |
|----------------------------|--------------|--------------------|
| `0x001ae6d8`               | “BackAmmo”   | Ammo HUD background |
| `0x001ae6e8`               | “OutlineAmmo”| Ammo outline/border |
| `0x001ae6f8`               | “WeaXP”      | Active weapon experience bar |
| `0x001ae700`               | “AmmoText”   | Font/Numeric text displaying the quantity |
| `0x001ae710`               | “AmmoIcon”   | Icon of the currently selected weapon |

## Mapping of Interface Text Strings (Bolt HUD) - Verified!

These strings configure the visual container that displays the total number of Bolts collected by the player.

| Virtual Address (EE RAM) | String Value | Confirmed Purpose |
|----------------------------|--------------|----------------------|
| `0x001ae720`               | “BackBolt”   | Visual background of the Bolt marker |
| `0x001ae730`               | “OutlineBolt”| Outline/outer border of the Bolt counter |
| `0x001ae740`               | “BoltText”   | Numeric text of the Bolt counter |

# Español

## Mapeo de Cadenas de Texto de la Interfaz (Ammo HUD)

Estas strings son utilizadas por el motor gráfico para cargar los assets visuales o etiquetas del contador de munición en el HUD.

| Dirección Virtual (EE RAM) | String Value | Propósito Estimado |
|----------------------------|--------------|--------------------|
| `0x001ae6d8`               | "BackAmmo"   | Fondo del HUD de munición |
| `0x001ae6e8`               | "OutlineAmmo"| Silueta/Borde de la munición |
| `0x001ae6f8`               | "WeaXP"      | Barra de experiencia del arma activa |
| `0x001ae700`               | "AmmoText"   | Fuente/Texto numérico que muestra la cantidad |
| `0x001ae710`               | "AmmoIcon"   | Icono del arma seleccionada actualmente |

## Mapeo de Cadenas de Texto de la Interfaz (Bolt HUD) - ¡Verificado!

Estas strings configuran el contenedor visual que muestra el total de guitones (Bolts) recolectados por el jugador.

| Dirección Virtual (EE RAM) | String Value | Propósito Confirmado |
|----------------------------|--------------|----------------------|
| `0x001ae720`               | "BackBolt"   | Fondo visual del marcador de guitones |
| `0x001ae730`               | "OutlineBolt"| Silueta/Borde exterior del marcador de guitones |
| `0x001ae740`               | "BoltText"   | Texto numérico del contador de guitones |
