Accepted by fresh complete-symbol and loaded-image gates, followed by guarded
proof publication. Exact-head CI and merge identity are recorded by the associated pull request.

The current authoring lot contains **1,003 new placements /41,180 physical C
bytes**, represented by **44 distinct qualified C sources and 45 family labels**.
Two labels reuse the same Count3 source. These are explicit program/address/size
intervals, not 1,003 newly discovered algorithms. The 40,000-byte minimum was

The lot adds 26 placements in existing default native units and 977 in separate

## Measured declaration context

Primary backend and assembler evidence explains a bounded source context: a
zero-argument `sda` attribute on an external four-byte integer view requests early
known-size extern emission under the existing optimized G8 profile. Ordinary
externs can be emitted later and retain the absolute/delay-slot forms observed
in other bodies. No compiler binary, assembler, profile option or source
algorithm was changed to obtain this behavior. See the existing
[compiler facts](COMPILER-NOTES.md) and [qualified tool requirements](../toolchain/requirements.json).

Two independent fresh controls—equals-three16 across 26 placements and
decrement/clamp28 across 14—matched complete symbols with the same pinned tools,
G8 flags and GP. Rechecking their immutable evidence adds no duplicate credit.
The qualified integer declaration context is used by **193 placements /6,292
bytes in nine families**, derived from the current authoring ledger and reviewed
source variants. Each attributed symbol has its own non-delay GP reference,
four-byte aligned view, undefined size-four object symbol and exclusively
GP-relative relocations. Standalone objects allocate no writable storage.

Ordinary absolute views may coexist with these GP views; their exact operands,
bindings and backing data remain checked independently. Delay-only declarations
remain ordinary where that context suffices. The four-word store retains its
earlier exact trial, while a declaration-only correction removes the unnecessary
attribute from its delay-only fourth cell; body, types and statement order remain
unchanged and the corrected source was requalified completely. This mechanism
does not establish original qualifiers, complete data-object sizes or ownership.
SDA pointers, aggregate objects and eight-byte views receive no generalized
admission from the integer controls. Ordinary floating setters/getters retain
their independently measured FPR ABI and introduce no SDA annotation.
