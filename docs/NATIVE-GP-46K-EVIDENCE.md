# Native and small-data C batch: 46,312 new physical bytes

Accepted by fresh complete-symbol and loaded-image gates, followed by guarded proof publication. Exact-head GitHub CI and merge identity are tracked by the associated pull request.

This batch adds 485 explicit overlay placements from 34 qualified source variants: 116 placements in the existing default native units and 369 in separate small-data units. The default native profiles remain unchanged, including Barlow's existing G8 profile. The new small-data units use the independently qualified existing G8 engine and fixed GP, with each reference operand and binding checked. These are additional physical placements, not 485 new algorithms.

All 321 separately reserved Qwen targets and equivalent body/JAL-shape copies are excluded across every program. The worker's research branch is not merged by this batch. Complete sizes and every byte are compared; no mask, partial prefix, ASM replacement, guessed helper implementation or approximate score contributes coverage.

Source is authored under `src/`, with explicit per-program catalogues and generated candidate units. Each small-data module owns its complete per-program C unit and is rendered once. The old Grelbin fragment is retained, and its previously generated C remains an exact prefix of the new complete module. Every old native function, binding, profile and generated source prefix is preserved. These authored module and partial structure boundaries do not establish original retail object ownership.

Source-specific corrections retain their evidence: signed flag masks match the observed negative immediate forms, a partial root view reuses independently qualified field context, and subsequent root state callbacks reuse that context. The 16 Barlow additions reuse unchanged already authored definitions under Barlow's existing default profile; their two previously qualified `nosda` extern declarations are preserved with pinned original declaration provenance. No new attribute is introduced to rescue a refusal. A further Barlow hypothesis and all unsuccessful GP/scalar/float/native trials remain retained.

Function descriptions record observed behavior and measured fields rather than invented game purposes. The sixteen new Barlow placements receive factual descriptions of their unchanged C definitions; generic or truncated inherited control descriptions are preserved in the original control entries. Unknown game roles, complete data-object boundaries and opaque helper implementations remain explicit limits.
